Unit 1: Networking · Topic 1 of 14

Internet Concepts

The Internet is a worldwide network of networks that follow common rules so any device can exchange data with any other.

Basic components

Clients (your phone or PC) ask for things. Servers store websites, mail and files. An ISP gives you access. Routers pass data along the best path. The backbone is the high-speed cable network, including undersea cables, that links countries. IP addresses and DNS say where things are.

Architecture: client–server

The Internet works on a request and reply model. Your data is cut into packets; each packet may travel a different route and is reassembled at the other end.
ClientISPRoutersServer
Remember
  • Internet = network of networks; the Web is only one service on it
  • Client asks, server answers
  • Data travels as packets and is reassembled

Quick check

Is the Internet the same as the WWW?

No. The WWW is a service (web pages) running on the Internet.

Protocols

A protocol is an agreed set of rules for communication. Different jobs use different protocols.

The ten you must know

ProtocolFull formJobPort
TCP/IPTransmission Control Protocol / Internet ProtocolSplits data into packets and delivers them–
SMTPSimple Mail Transfer ProtocolSends email25
POP3Post Office Protocol 3Downloads email to your device110
HTTPHyperText Transfer ProtocolLoads web pages80
HTTPSHTTP SecureEncrypted web pages443
SSHSecure ShellSecure remote login22
SFTPSSH File Transfer ProtocolSecure file transfer22
FTPFile Transfer ProtocolPlain, unencrypted file transfer21
SCPSecure Copy ProtocolSecure file copy over SSH22
TELNETTeletype NetworkPlain, unencrypted remote login23

How to remember

Secure group: HTTPS, SSH, SFTP, SCP encrypt data. Insecure group: HTTP, FTP, TELNET send plain text. For mail: SMTP Sends, POP3 Pulls.
Remember
  • S in a name usually means Secure
  • SFTP and SCP ride on SSH
  • TELNET and FTP are not encrypted

Quick check

Which protocol sends email and which receives it?

SMTP sends; POP3 receives (downloads).

Web Services and Mobile Technologies

A web service lets one program use another program’s features over the Internet. Mobile generations decide how fast you get data on the move.

Web services

A weather app does not measure weather itself; it asks a weather service over the Web and shows the answer. Other examples: online payment, maps, login with Google. The programs swap data in standard formats such as XML or JSON.

3G, 4G and 5G

GenerationSpeed (typical)What it brought
3GA few MbpsMobile web, video calls
4G (LTE)Tens to hundreds of MbpsHD streaming, app-based services
5GUp to Gbps, very low delayIoT, telemedicine, self-driving vehicles
Remember
  • Web service = program-to-program over the Web
  • Each generation is faster with lower delay
  • 5G suits real-time and IoT uses

Quick check

What does the G stand for?

Generation of mobile technology.

Unit 2: HTML · Topic 4 of 14

Web Page Design Basics

HTML (HyperText Markup Language) describes the structure of a web page. You write it as plain text and the browser draws it.

Create, save, open

1. Open Notepad. 2. Type your HTML. 3. Choose Save as, set type to All Files, name it page.html. 4. Double-click the file to open it in a browser. 5. Edit, save, then press refresh to see changes.

Minimal page

<!DOCTYPE html>
<html>
<head><title>My first page</title></head>
<body>Hello, world!</body>
</html>

Try it yourself:

Remember
  • Save with the .html extension
  • Browser shows body content; the title goes in the tab
  • Refresh after every save

Quick check

Why do we choose All Files while saving?

Otherwise Notepad adds .txt and the browser will not treat it as a web page.

Unit 2: HTML · Topic 5 of 14

Structure and Text Formatting

Structure tags build the skeleton; formatting tags style the text inside it.

Structure tags

<html> wraps everything. <head> holds information about the page. <title> sets the tab text. <body> holds what you see.

Formatting tags

TagEffect
<h1>–<h6>Headings, h1 largest
<p>Paragraph
<b> <i>Bold, italic
<br>Line break (empty tag)
<hr>Horizontal line (empty tag)
Remember
  • Pair tags have a closing tag; br and hr do not
  • Only body content is displayed
  • Headings: smaller number = bigger text

Quick check

Which tag draws a line across the page?

<hr>

Unit 2: HTML · Topic 6 of 14

Lists and Tables

Lists group items; tables arrange data in rows and columns.

Three kinds of list

<ul> bullets, <ol> numbers, both with <li> items. A description list uses <dl>, with <dt> for the term and <dd> for its meaning.

Tables

Read it as table → rows (tr) → cells (th heading, td data). colspan merges cells across columns; rowspan merges them down rows.
Remember
  • ul = bullets, ol = numbers, dl = term and meaning
  • colspan = across, rowspan = down
  • th is bold and centred by default

Quick check

Which attribute merges two rows into one cell?

rowspan="2"

Unit 2: HTML · Topic 7 of 14

Multimedia and Images

Images, sound and video make pages come alive. Each is added with one tag and a file name.

Images

<img src="cat.jpg" width="200" height="150" alt="A cat"> src is the file, width and height set size, alt is text for when the image fails and for screen readers.

Audio and video

<audio src="song.mp3" controls></audio>
<video src="clip.mp4" width="320" controls></video>
The controls attribute shows play and pause buttons.

Superscript and subscript

<sup> raises text (x2); <sub> lowers it (H2O).
Remember
  • img is an empty tag
  • alt helps accessibility
  • Add controls to audio and video

Quick check

What does alt do?

Gives replacement text if the picture cannot load and describes it to screen readers.

Unit 2: HTML · Topic 8 of 14

Forms and Links

Links connect pages; forms collect information from visitors.

Links

<a href="page2.html">Next</a> opens another page. href="mailto:me@mail.com" opens the email app. target="_blank" opens the link in a new tab.

Form controls

All sit inside <form>. Text box type="text", password type="password" (hides characters), radio (choose one), checkbox (choose many), and a drop-down list with <select> and <option>.
Remember
  • Radio = one choice; checkbox = many
  • Password type hides what is typed
  • target=_blank opens a new tab

Quick check

Which input type hides characters?

password

Unit 2: HTML · Topic 9 of 14

Cascading Style Sheets (CSS)

CSS controls how HTML looks: colours, spacing, fonts and layout. HTML is the content; CSS is the style.

Two ways to apply it

Inline goes in one tag: <p style="color:red">. Internal sits in the head inside <style> and styles many elements at once. Rule shape: selector { property: value; }

Properties to know

color, background-color, border, margin (space outside), width and height, font-family, font-size, text-align, and float (pushes an element left or right so text wraps around it).
Remember
  • Inline = one tag; internal = whole page
  • margin is outside the border
  • float lets text wrap around an element

Quick check

Where does an internal style sheet go?

Inside a style tag in the head section.

Unit 3: Cyber Ethics · Topic 10 of 14

Netiquettes

Netiquette is good manners on the Internet. Online words last, so behave as you would in person.

Golden rules

Be respectful and polite. Do not type in ALL CAPS (it reads as shouting). No spam, chain messages or offensive language. Think before posting; it can stay forever. Respect others’ privacy and never share their photos or details without consent. Give credit when you use others’ work. Keep a professional tone in school and work messages.

Digital professionalism

Use a clear subject line, proper greetings and correct spelling in emails. Do not reply in anger; pause first. Keep personal accounts and school accounts separate.
Remember
  • Polite, honest, respectful
  • No spam and no shouting
  • Your digital footprint is permanent

Quick check

Why avoid writing in all capitals?

It looks like shouting and seems rude.

Unit 3: Cyber Ethics · Topic 11 of 14

Software Licensing and Open Source

A software licence is the legal permission that says how you may use, copy or change a program.

Free versus paid

TypeMeaning
Proprietary (paid)Bought; code is secret; you cannot modify or share it
FreewareFree to use, but code is not open
SharewareFree trial, then you must pay
Open sourceCode is public; you may study, change and share it

Open-source community

Developers worldwide improve open-source software together, which makes it low-cost, flexible and fast to fix. Examples: Linux, Firefox, LibreOffice. Licences such as GPL and MIT set the sharing rules. Free software means freedom to use and change, not always zero price.
Remember
  • Licence = legal permission
  • Open source = code visible and changeable
  • Freeware is not the same as open source

Quick check

Is freeware always open source?

No. Freeware is free to use but its code may be closed.

Intellectual Property Rights (IPR)

IPR are legal rights over creations of the mind, including digital content.

Types

Copyright protects writing, music, art and code. Patent protects inventions. Trademark protects names, logos and slogans. Creators own their digital work from the moment it is made.

Fair use and plagiarism

Fair use allows limited use of copyrighted work, such as short quotes for study or review, with credit. Plagiarism is copying someone’s work and presenting it as your own. Consequences: failing marks, loss of reputation, legal action and fines. Always cite your sources.
Remember
  • Copyright, patent, trademark = IPR
  • Fair use is limited and credited
  • Plagiarism has academic and legal penalties

Quick check

Which IPR protects a company logo?

A trademark.

Unit 3: Cyber Ethics · Topic 13 of 14

Accessibility and Society

Technology should be usable by everyone, but not everyone has equal access.

Freedom of information

People have the right to seek and share information, which supports education, free speech and fair governance. This freedom must be balanced with privacy and the law.

The digital divide

The gap between people who have technology and Internet and those who do not. Causes: poverty, rural location, lack of skills, language barriers. Fixes: low-cost data, public Wi-Fi, digital literacy classes, content in local languages.

Accessible design

Use alt text for images, captions for video, high-contrast colours, keyboard navigation and screen-reader support so people with disabilities can use the Web.
Remember
  • Digital divide = access gap
  • Accessibility includes everyone
  • Freedom of information has limits

Quick check

Name two causes of the digital divide.

Poverty and lack of infrastructure or skills.

Unit 3: Cyber Ethics · Topic 14 of 14

E-commerce Security

E-commerce means buying and selling online, so protecting money and data is vital.

Making transactions safe

Look for https:// and the padlock. SSL/TLS encrypts data between you and the site so thieves cannot read card numbers. Use trusted sites, strong passwords, two-factor authentication and never share OTPs.

Risks and prevention

Fraud: fake shops, phishing links, card skimming. Privacy: sites collect your data, so read policies and share only what is needed. Prefer secure payment gateways, check statements often and report fraud quickly.
Remember
  • HTTPS + padlock = encrypted connection
  • SSL/TLS protects data in transit
  • Never share OTP or PIN

Quick check

What does the padlock in the address bar show?

The connection is encrypted with SSL/TLS (HTTPS).
